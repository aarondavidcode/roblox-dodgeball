# For parents

This repo holds **instructions and Lua scripts** for a family dodgeball project. The **playable game** is always a **Roblox experience** you create and save in **Roblox Studio**—not this GitHub repository.

---

## Repo vs Roblox place

| | **This GitHub repo** | **Your Roblox place** |
|--|----------------------|------------------------|
| What it is | Markdown guides + copy-paste scripts | The 3D world, teams, and live game |
| Who edits it | Browser; kids copy scripts into Studio | Roblox Studio on your computer |
| Where friends play | They do not play here | Published experience on Roblox |

Think of GitHub as the **recipe book** and Roblox as the **kitchen**.

---

## Accounts and Studio

- Install Studio from [create.roblox.com](https://create.roblox.com).
- Children under 13 should use an account under your family’s rules (often a parent-owned account with you supervising Studio).
- Save work with **File → Save to Roblox** or **Save to File** on your computer as backups.

---

## Publishing and privacy

1. In Studio: **File → Publish to Roblox**.
2. On [create.roblox.com](https://create.roblox.com), open the experience’s settings.
3. Prefer **Private** (or invite-only) until you are comfortable with who can join.
4. Sharing the **GitHub link** does not publish the game—it only shares guides. Sharing the **Roblox experience link** is what lets people play.

Review [Roblox community standards](https://create.roblox.com/docs/production/publishing/publishing-experiences-and-places) and your household rules before going public.

---

## Sharing this project with kids

- Clone or bookmark **https://github.com/aarondavidcode/roblox-dodgeball** and follow folders `01` → `06` in order for the full lobby + match flow.
- For scripts, use GitHub’s file view or **Raw** to copy text—no need to download the whole repo unless you want to.
- When this repo updates, kids can paste new script versions into **ServerScriptService** without rebuilding the map.
